# Smrithi S. — Cloud & Security Portfolio

A minimal, professional portfolio website showcasing my skills, projects, education, certifications, and experience in **Cloud Computing, Cloud Security, and Web Development**.

The portfolio is built using **Python Flask, HTML, CSS, and JavaScript**, with a clean and responsive design suitable for both desktop and mobile devices.

## 1. Run it locally

You’ll need **Python 3.x** installed on your system.

### Clone the repository

```bash
git clone https://github.com/Smrithi0/your-repository-name.git
cd your-repository-name
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the Flask application

```bash
python app.py
```

Open the local URL shown in the terminal, usually:

```text
http://127.0.0.1:5000
```

The portfolio will be available in your browser.

## 7. Deployment

The Flask portfolio can be deployed using cloud hosting platforms such as **Microsoft Azure App Service**.

A typical deployment workflow is:

```text
Local Flask Application
        ↓
      Git
        ↓
     GitHub
        ↓
 Azure App Service
        ↓
  Live Portfolio
```

The project can be updated by pushing the latest changes to the GitHub repository and redeploying the application.
